Импорт стихов из JSON файла

{% csrf_token %}

Выберите автора по умолчанию для стихов, у которых в JSON нет author_id. Если в JSON есть author_id, будет использован он.

Выберите JSON файл со стихами. Формат: массив объектов с полями author_id (опционально), tag_ids (опционально), title, body, createdAt (опционально), epigraph (опционально), likes (опционально)

Отмена

Формат JSON файла:

[
  {
    "author_id": 1,
    "tag_ids": [1, 2, 3],
    "title": "Название стиха",
    "body": "Текст стиха",
    "createdAt": "2024",
    "epigraph": "Эпиграф (опционально)",
    "likes": 0
  }
]

Примечания:

  • Поле author_id опционально. Если оно отсутствует, будет использован автор по умолчанию из формы выше.
  • Поле tag_ids опционально. Должно быть массивом ID тегов. Если тег с указанным ID не найден, он будет пропущен.
